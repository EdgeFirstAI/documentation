# Dataset Tutorials

This section contains tutorials for creating and managing datasets in EdgeFirst Studio.

A typical workflow begins with [capturing data](capture.md), which can be done with any device with a camera such as a phone. For more advanced use cases, such as [training Fusion models](../../models/training/fusion.md), you will need a [Raivin platform](../../platforms/quickstart/raivin/index.md), which combines camera and radar or LiDAR sensors to enable 3D data collection and annotation.

After collecting your data, the next step is to upload into EdgeFirst Studio and start [annotating your dataset](annotations/index.md). If you already have an annotated dataset in a supported format, such as Darknet, you can [import the dataset](import.md) directly into EdgeFirst Studio for review, curation, and further development.

Once your datasets are available in EdgeFirst Studio, you can find [additional tools](management.md) to edit, copy, split, combine, and tag datasets and more!
