# Dataset Tutorials

This section contains the dataset tutorials which provide instructions for creating datasets from scratch.  You typically start by [capturing data](capture.md) for your dataset which can be achieved by using a device such as a mobile phone.  However, for more specialized dataset captures such as [training Fusion models](../../models/training/fusion.md) you will need a [Raivin platform](../../platforms/quickstart/raivin/index.md) which integrates the Camera and Radar or LiDAR for 3D annotations.  Once you have captured some data, you will need to upload your data into EdgeFirst Studio for [annotation](annotations/index.md).  If you already have annotated datasets that is in Darknet format for example, you can choose to [import](import.md) your dataset into EdgeFirst Studio for curation and viewing. Lastly, you can [manage your datasets](management.md) in EdgeFirst Studio such as copying datasets, splitting datasets, and much more!
