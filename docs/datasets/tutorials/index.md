# Dataset Tutorials

Welcome to the Dataset Tutorials!  In this section you will learn how to [capture](capture.md), [annotate](annotations/index.md), [manage](management.md) and [import](import.md) datasets.  You can capture datasets using any device with a camera such as a phone.  However, for more specialized dataset captures such as training Fusion models you will need a [Raivin platform](../../platforms/index.md) which integrates the Camera and Radar or LiDAR for 3D annotations.  Furthermore, EdgeFirst Studio offers tools to make the annotation process as seamless as possible by integrating SAM-1 and SAM-2 for auto-annotation features, but also providing the tools to manually add annotations for your own choosing.  Lastly, you can manage your datasets in EdgeFirst Studio from importing new datasets, copying datasets, splitting datasets, and much more!
