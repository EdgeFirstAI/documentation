## COCO


**[COCO (Common Objects in Context)](coco.md)** is a large-scale dataset designed for object detection, segmentation, keypoint detection, and captioning tasks in computer vision. It contains:

- **Images**: Over 330,000 images, with more than 200,000 labeled.
- **Objects**: 1.5 million object instances across **80 object categories**.
- **Annotations**: Includes bounding boxes, instance segmentations, keypoints for person detection, and image captions.
- **Context**: Objects are labeled within complex everyday scenes, enabling models to learn in-context recognition rather than isolated object classification.
- **Evaluation Server**: Supports standardized benchmarking with well-defined splits and evaluation metrics, widely used for comparing object detection and segmentation models.

**Key Features:**
- Instance segmentation masks
- Dense keypoints for human pose estimation
- Captions for image captioning research
- Large-scale, richly annotated dataset supporting multi-task research in computer vision.
