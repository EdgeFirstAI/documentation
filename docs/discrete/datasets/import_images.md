1. Click on the Apps waffle menu at the top navbar as indicated below. Then click on the "Apps" button to navigate to the list of apps in Studio.

    {{ figure("/studio/assets/navigation/apps_button.png", "Apps Button") }}

2. Click on the importer set of apps.

    {{ figure("/studio/assets/navigation/importer_apps.png", "Importer Apps") }}

3. Click "Run App" on the image importer app as shown below.

    {{ figure("/datasets/assets/import/image_importer.png", "Image Importer App") }}

4. Click on "select files" to select image files from your local machine.

    The supported image formats are `.jpg`, `.jpeg`, `.png`, `.bmp`, `.webp`, `.tif`, `.tiff`, `.heic` and `.heif`.  A `.zip` archive of images or a folder can also be selected.  HEIC and HEIF images are converted to PNG on import.

    {{ figure("/datasets/assets/import/drag_drop_images.png", "Drag and Drop Image Files") }}

5. Once the files have been selected follow the steps as shown below.

    {{ figure("/datasets/assets/import/import_images.png", "Import Images") }}

6. Navigating to your project should now contain a new dataset with the imported images.

    {{ figure("/datasets/assets/import/imported_images.png", "Imported Images") }}
