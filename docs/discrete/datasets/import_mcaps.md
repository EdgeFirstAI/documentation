If you have an MCAP recording [captured from either a Maivin/Raivin platform](../../datasets/tutorials/capture.md#capture-with-an-edgefirst-platform), you can import the MCAP into a dataset in EdgeFirst Studio.

1. Click on the Apps waffle menu at the top navbar as shown below. This will open another panel, then click on the "APPS" button to navigate to the "APPS" page.

    {{ figure("/studio/assets/navigation/apps_button.png", "Go to Apps") }}

2. Click on the importer set of apps.

    {{ figure("/studio/assets/navigation/importer_apps.png", "Apps Page") }}

3. Find the "MCAP Importer" app and click the "Run App" button for the app. This will open the settings for the MCAP importer app to configure the import process.

    {{ figure("/datasets/assets/import/mcap_importer.png", "MCAP Importer App") }}

4. Click "Choose Files" to select MCAP file(s) from your PC. Drag and drop selected files into the app as shown.

    {{ figure("/datasets/assets/import/drag_drop_mcap.png", "Drag and Drop MCAP Files") }}

5. Click "upload" to upload the selected files.

    {{ figure("/datasets/assets/import/upload_mcap_button.png", "Upload Selected MCAP") }}

6. Configure the following settings:

    * Project: specify which project the dataset is stored.
    * Dataset name and description: if the name is left empty, the MCAP name is used.
    * MCAP topic settings: enable "Use MCAP Selected Topics" to choose topics and adjust the frame rate.
    * Annotation source: either specify a model to publish pre-generated annotations for the dataset from the choices: 'the MCAP model topic', 'YOLOx model trained on COCO classes', 'custom model trained in Studio for custom labels', 'no annotations'.
    * Depth generation: optional AI depth maps for each frame for 3D bounding box accuracy improvements (optional).

    {{ figure("/datasets/assets/annotations/automatic/restore_mcap_prompts.jpg", "Import MCAP Configuration") }}

7. Click **START APP** to begin the import, then click **Tasks** on the Studio navbar to monitor its progress. Once the process completes, open the dataset using the dataset link on the task card.

    {{ figure("/datasets/assets/annotations/automatic/restore_mcap_task.jpg", "Process Completed") }}

8. Then click on the sequence to navigate to the gallery to view individual frames and annotations generated by the process.

    {{ figure("/datasets/assets/annotations/automatic/imported_mcap_sequence.jpg", "Imported MCAP Sequence") }}

9. The auto-generated annotations (if selected) should be visible throughout the frames.

    {{ figure("/datasets/assets/annotations/automatic/restored_mcap_result.jpg", "Resulting Restored MCAP") }}

    If the snapshot was restored into a dataset without any annotations or some frames are missing annotations, you can also follow through the [Dataset Annotations Tutorials](../../datasets/tutorials/annotations/automatic.md) to annotate your dataset with 2D or 3D annotations in EdgeFirst Studio.
