1. Click on the Apps waffle menu at the top navbar as indicated below. Then click on the "Apps" button to navigate to the list of apps in Studio.

    {{ figure("/studio/assets/navigation/apps_button.png", "Apps Button") }}

2. Click on the importer set of apps.

    {{ figure("/studio/assets/navigation/importer_apps.png", "Importer Apps") }}

3. Click on "Run App" on the video importer app.

    {{ figure("/datasets/assets/import/video_importer.png", "Video Importer App") }}

4. Click on “Choose Files” which opens a dialog for selecting files from your local machine. Drag and drop selected files into the app as shown.

    {{ figure("/datasets/assets/import/drag_drop_videos.png", "Drag and Drop Video Files") }}

5. Once the files have been selected follow the steps as shown below.

    {{ figure("/datasets/assets/import/import_videos.png", "Import Videos") }}

6. Once started, the video import progress should be shown below.

    {{ figure("/datasets/assets/import/video_import_process.png", "Video Import Progress") }}

7. Once complete, you can navigate to the dataset with the imported captures by clicking on the link as shown.

    {{ figure("/datasets/assets/import/video_import_completed.png", "Completed Video Import") }}

    This link navigates to the imported videos in EdgeFirst Studio. Each card represents each video that was imported. Clicking on a card will open the video for playback and visualization of each frame.

    {{ figure("/datasets/assets/import/imported_videos.png", "Imported Videos") }}
