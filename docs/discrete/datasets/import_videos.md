1. Click on the Apps waffle menu at the top navbar on the top navbar as shown below. This will open another panel, then click on the "APPS" button to navigate to the "APPS" page

    {{ figure("/studio/assets/navigation/apps_button.png", "Go to Apps") }}

2. Click on the importer set of apps

    {{ figure("/studio/assets/navigation/importer_apps.png", "Apps Page") }}

3. Find the "Video Importer" app and click the "Run App" button associated to the app. This will open the settings for the video importer app to configure the video import process

    {{ figure("/datasets/assets/import/video_importer.png", "Video Importer App") }}

4. Click "Choose Files" to select video files from your PC. Drag and drop selected files into the app as shown

    {{ figure("/datasets/assets/import/drag_drop_videos.png", "Drag and Drop Video Files") }}

5. Once the files have been selected, import the videos by following the steps as shown below

    {{ figure("/datasets/assets/import/import_videos.png", "Import Videos") }}

6. Once started, the video import progress should be shown below

    {{ figure("/datasets/assets/import/video_import_process.png", "Video Import Progress") }}

7. Once complete, you can navigate to the dataset with the imported captures by clicking on the link as shown

    {{ figure("/datasets/assets/import/video_import_completed.png", "Completed Video Import") }}

    The link will navigate you to the imported videos. There were four videos imported and each card represents each video that was imported. Clicking on a card will open the video for playback and visualization of each frame

    {{ figure("/datasets/assets/import/imported_videos.png", "Imported Videos") }}
