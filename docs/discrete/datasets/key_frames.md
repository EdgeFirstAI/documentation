# Key Frames

!!! bug "This feature is currently not operational"

    Please refrain from using this tool as there are still issues that are currently being fixed.

This feature is another method for automatically generating annotations. It requires a start and end frame and the tool generates the annotation through the interpolation beween these two frames. However, we still recommend using the [Automatic Ground Truth Generation](../../3D/annotations/index.md#automatic-ground-truth-generation) as it remains the superior method of auto-annotating; requiring only the first frame as the prompt.

When annotating a sequence, key frames let you annotate an object on a few frames and have Studio fill in the frames between them.  Studio linearly interpolates the 2D box and/or the 3D box between the key frames.

1. Open the sequence in the annotation editor.

    {{ figure("/3D/assets/click_3d_sequence.jpg", "Pick a Sequence") }}

2. Click the **Key Frame Editing** button in the 2D canvas toolbar.

    <!-- SCREENSHOT: assets/keyframe-toggle.jpg - 2D toolbar with the Key Frame Editing button highlighted and enabled -->

3. On the first frame where the object appears, select its annotation.  The selected annotation becomes a key frame of the object.  Deselecting an annotation removes it from the key frame sequence.
4. Move to another frame, adjust or draw the annotation for the object and select it to add another key frame.  Add as many key frames as needed to follow the object, for example every time it changes direction or speed.

    <!-- SCREENSHOT: assets/keyframe-timeline.jpg - Key frame timeline below the image showing one row for the object with circles on each key frame -->

5. Click **Interpolate Annotations**.  Studio creates the annotations for every frame between the key frames, shown as dotted (unsaved) annotations.
6. Step through the frames to preview the result.  If the annotations follow the object, click **Save New Annotations**.

    <!-- SCREENSHOT: assets/keyframe-interpolated.jpg - Sequence ribbon showing the Interpolate Annotations and Save New Annotations buttons, with dotted interpolated boxes on an in-between frame -->

!!! note
    - Key frame interpolation applies to sequences only, and covers 2D boxes and 3D boxes.  Polygons are not interpolated.
    - The key frame sequence is built for one object at a time, with as many key frames as needed.
    - Key frames are only kept in the editor until they are interpolated, so interpolate and save before leaving the sequence.
    - Review the interpolated frames.  Annotations are generated by a straight line between the key frames and will not follow movement that is not linear.
