# Key Frames

!!! warning "This feature currently only supports 2D and 3D bounding boxes"

    Only 2D and 3D bounding boxes can be generated using this method. 
    Segmentation masks/polygons are not yet supported.

This feature is another method for automatically generating annotations. It requires a start and end frame and the tool generates the annotation through the interpolation between these two frames. However, we still recommend using the [Automatic Ground Truth Generation](../../3D/annotations/index.md#automatic-ground-truth-generation) as it remains the superior method of auto-annotating; requiring only the first frame as the prompt.

When annotating a sequence, key frames let you annotate an object on a couple frames and have Studio fill in the frames between them.  Studio linearly interpolates the 2D box and/or the 3D box between the key frames.

1. Open the sequence in the annotation editor.

    {{ figure("/3D/assets/click_3d_sequence.jpg", "Pick a Sequence") }}

2. Add labels to your dataset if it doesn't already have labels

    {{ figure("/3D/assets/add_3d_labels.jpg", "Add 3D Labels") }}

3. Enable LiDAR or Radar Point Clouds (if available) for generating 3D bounding boxes.

    {{ figure("/3D/assets/pcd_visibility.jpg", "Enable PCD Visibility") }}

4. Click the **Key Frame Editing** button in the 2D canvas toolbar.

    {{ figure("/datasets/assets/annotations/manual/key_frame_mode.jpg", "2D toolbar with the Key Frame Editing button highlighted") }}

5. Draw a bounding box around the object in the frame using the "Box Tool" or by pressing "B" on your keyboard.

    {{ figure("/datasets/assets/annotations/manual/box_tool.jpg", "Bounding box added around the object in the frame") }}

6. Select the drawn object by either clicking on the object or pressing the "down" arrow key on your keyboard. The selected annotation becomes a key frame of the object.  Deselecting an annotation removes it from the key frame sequence.

    {{ figure("/datasets/assets/annotations/manual/key_frame_select_object.jpg", "Selected annotated object") }}

7. If LiDAR/Radar PCDs are available, select the "Clustering Mode" or press "C" on your keyboard to draw a 3D bounding box around the cluster representing the object in your frame.

    {{ figure("/datasets/assets/annotations/manual/key_frame_clustering_mode.jpg", "3D Bounding box around the object's PCD cluster") }}

8. Move forward to the next frames by pressing the "right" arrow key to select and annotate your end frame. It is important to note that the objects should move in a linear fashion in the selected frames such that the interpolated annotations properly follows the object.

9. Once an end frame has been selected, repeat steps 5-7 to generate 2D and 3D bounding boxes for this frame. Then click **Interpolate Annotations**.  Studio creates the annotations for every frame between the key frames, shown as dotted (unsaved) annotations.

    {{ figure("/datasets/assets/annotations/manual/key_frame_interpolate_annotations.jpg", "Interpolate Annotations button") }}

10. Step through the frames to preview the result.  If the annotations follow the object, click **Save New Annotations**.

    {{ figure("/datasets/assets/annotations/manual/key_frame_save_new_annotations.jpg", "Save New Annotations button") }}

!!! note "Current Feature Limitations"
    - Key frame interpolation applies to sequences only, and covers 2D boxes and 3D boxes.  Polygons are not interpolated.
    - The key frame sequence is built for one object at a time, with as many key frames as needed.
    - Key frames are only kept in the editor until they are interpolated, so interpolate and save before leaving the sequence.
    - Review the interpolated frames.  Annotations are generated by a straight line between the key frames and will not follow movement that is not linear.
