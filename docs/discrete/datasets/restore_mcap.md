From the snapshots page, select the MCAP you plan to restore into a dataset.  The click on the snapshot's extended menu as shown and select "restore".

Specify the app parameters to configure your dataset import based on the description below.

{{ img("/datasets/assets/annotations/automatic/restore_mcap_prompts.jpg", "Restore MCAP Configuration") }}

If the snapshot was restored into a dataset without any annotations, you can also follow through the [Dataset Annotations Tutorials](../../datasets/tutorials/annotations/automatic.md#semi-automatic-ground-truth-generation) to annotate your dataset in EdgeFirst Studio.
