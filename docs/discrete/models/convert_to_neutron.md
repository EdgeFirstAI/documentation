# Neutron Conversion

In this section, you will find instructions for converting quantized TFLite models to NXP eIQ Neutron format using EdgeFirst Studio for NPU-accelerated inference on i.MX 95, i.MX 943, and other NXP silicon.

1. Click on the completed training session

	{{ figure("/models/assets/training/vision-view-train-details.jpg", "Completed Training Session") }}

2. Navigate to the "Artifacts" tab and click on the "NXP eIQ Neutron Converter" button under "Converters" on the right

	{{ figure("/models/assets/conversion/neutron-converter-button.jpg", "Neutron Converter") }}

3. Select the target device for deploying the model.  Then click on "Start App" to start the conversion process

	{{ figure("/models/assets/conversion/neutron-converter-options.jpg", "Neutron Converter Options") }}
