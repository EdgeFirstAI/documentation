# Specify Project Experiments

From the projects page, choose the project that contains the training session with the models you want to validate.  In this example, the project chosen is the "Object Detection" project that was created in the [Getting Started](../../getting_started/create_project.md).  Next click the "Model Experiments" button as indicated in red.

{{ figure("/models/assets/training/vision-model-experiments.jpg", "Model Experiments") }}

## Create Validation Session

In the experiment card, click the "Validate Sessions" button as indicated in red below.

{{ figure("/models/assets/validation/vision-validation-sessions.jpg", "Validate Sessions") }}

You will be greeted to the "Validate Sessions" page as shown below.

{{ figure("/models/assets/validation/vision-validation-sessions-page.jpg", "Validate Sessions Page") }}

Start a validation session by clicking on the "New Session" button on the top right corner of the page.

{{ figure("/models/assets/training/new-session-button.jpg", "New Session Button") }}
