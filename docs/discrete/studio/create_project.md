1. From the [User Home Page](../../studio/home.md) screen, click the "Projects" button.

    {{ figure("/studio/assets/user/home-page-goto-projects.png", "Go To Projects") }}

2. Now that you are in the "Projects" page, create your first project by clicking on the "New Project" button on the top-right corner of the page.

    {{ figure("/studio/assets/projects/create-project.jpg", "Create Project") }}

3. Provide a name and a description of the project as shown in the example below.  Click the "Create" button to create your new project.

    {{ figure("/studio/assets/projects/create-project-fields.jpg", "Project Details") }}

4. Your created project will be shown like the example below.  

    {{ figure("/studio/assets/projects/new-project.jpg", "New Project") }}
