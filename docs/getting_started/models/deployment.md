# Model Deployment

We provide support for model deployment on various platforms.  Deploying ModelPack requires an input image.  This could either be from an image file, video file, or live on a device with a camera.  Deploying Fusion requires an input image and an input Radar cube.  Currently deployment is supported on a Raivin which contains a camera and a Radar module.
