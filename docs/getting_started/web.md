# Web-Based Workflow

In this workflow, we will explore recording a video or capturing images using a mobile device and then upload the captured data into EdgeFirst Studio for annotation, model training, model validation, and then model deployment. This workflow requires the user to have signed up and logged in to EdgeFirst Studio and followed the initial steps described in the [EdgeFirst Studio Quickstart](../index.md#edgefirst-studio-quickstart).

## 1. Capture Data Using a Mobile Device

In this workflow, we will be exploring capturing images samples of coffee cups for training a detection model that detects coffee cups. However, you can chose any type of objects in your dataset, but be mindful that the label for these objects remains consistent for all samples.
