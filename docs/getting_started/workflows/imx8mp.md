# i.MX 8M Plus Workflow

In this workflow, you will explore copying the Coffee Cup dataset from "Sample Project" and using the dataset to train a vision model that detects coffee cups.  Once the model is trained, you will see how to convert it for the i.MX 8M Plus NPU, validate the model on target, and deploy it.

This workflow expects that you have a PC with internet access and an [i.MX 8M Plus](../../platforms/quickstart/imx8mplus/index.md) already set up and accessible on your network.
