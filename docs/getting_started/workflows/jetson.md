# Jetson Orin Workflow

In this workflow, you will explore copying the Coffee Cup dataset from "Sample Project" and using the dataset to train a vision model that detects coffee cups.  Once the model is trained, you will see how to validate the model and then finally deploy the model on the Jetson Orin.

This workflow expects that you have a PC with internet access and a [Jetson Orin](../../platforms/quickstart/jetson_orin/index.md) already setup and accessible in your network.
