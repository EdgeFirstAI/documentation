# Profiler+ Workflow

In this workflow, you will retrain an Ultrlaytics model, revalidate it using [edgefirst-profiler](../../profiler/index.md), and compare your results against the [EdgeFirst Model Zoo on Hugging Face](https://huggingface.co/spaces/EdgeFirst/Models) baselines.  Models can be deployed on the browser or on a compatible target device.
