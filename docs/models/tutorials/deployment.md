# Deployment

we provide support for model deployments on various platforms.  Deploying ModelPack requires an input image.  This could either be from an image file, video file, or live on a device with a camera.  Deploying Fusion requires an input image and an input Radar cube.  Currently deploying Fusion models is only supported on a Raivin which contains a camera and a Radar module. 

## ModelPack

You can find examples and tutorials for deploying ModelPack on various platforms.  

1. [Deploying to the PC](../modelpack/deployment/pc.md)
2. [Deploying to the EVK](../modelpack/deployment/evk.md)
3. [Deploying to the Maivin](../modelpack/deployment/maivin.md)
