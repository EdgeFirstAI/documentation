# Foxglove with 4K

This document introduces an example [Foxglove Studio][foxglove] layout displaying the 4 video tiling streams generated by [the Camera service](camera_4k.md). For more information about EdgeFirst Perception Middleware integration with Foxglove, read the [Foxglove Studio introduction](../data_collection/foxglove.md).

## Recording the 4K Topics

The [Recording Service](../data_collection/recording.md), by default, [cannot be configured through the Web UI to capture the 4K video tiling topics](../../platforms/configuration/mcap_recording.md#caveats), but it can be [configured manually](../../platforms/configuration/mcap_recording.md#adding-topics-manually-to-the-recording-service). Please follow the instructions here to configure the recorder service before starting to record the 4K streams.

## Foxglove Studios

Once the 4K topics are recorded and the MCAP file downloaded, once the MCAP file is loaded into Foxglove Studio, the four topics appear as standard video topics.
