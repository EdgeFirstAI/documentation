# EdgeFirst Platforms User Manual

This manual covers the EdgeFirst Perception Middleware for:

- **Maivin**: Vision-only configuration
- **Raivin**: Combined vision and radar configuration

If you have a new Maivin or Raivin, start with the [Quickstart Guide](./quickstart.md) to unbox and set up your device.
